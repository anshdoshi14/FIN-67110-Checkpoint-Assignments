# Personal persona worksheet

The existing role files retain inherited Checkpoint 1 baseline role instructions and added technical interface constraints.

For each of the following, open its corresponding file in `roles/`:

- Research Analyst (`research_analyst.md`)
- Financial Analyst (`financial_analyst.md`)
- Investment Advisor (`investment_advisor.md`)

For each role, write six parts:

1. **Identity:** two original sentences describing the analyst's professional viewpoint.
2. **How this role reads a company:** which filing section gets attention first and what noise gets ignored.
3. **Given:** exact source and other graph states provided to the role, not outside data.
4. **Criteria scored:** a numerical score/threshold for each priority, with a specific number and its real filing line or XBRL tag. Do not invent a score or source.
5. **What changes the view:** one observable event or next-filing measure that reverses the role's current position.
6. **Output:** exactly which of the five report sections it owns, finishing with `Insight:` and one source-backed statement from a filing that the earnings release's first paragraph does not state; include `10-K L000123` or `EX-99.1 L000123` as appropriate.

Do not claim you wrote the personas until you actually do. Each company should be analyzed using the same company-neutral persona rules.
